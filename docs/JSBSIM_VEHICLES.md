# JSBSim physics for the F-35B, F-15E, A320, helicopter and DeLorean

Code: `Assets/Scripts/Sim/Flight/JsbFdm.cs` + `JsbEngine.cs` (engine-free interpreter of JSBSim aircraft files), `Assets/Scripts/Runtime/Vehicles/JsbVehicleModel.cs`
(`JsbJetModel : IVehicleModel`, wired in `VehiclePhysicsFactory.Create`), data in `Assets/Resources/Flight/jsb/`.

| Vehicle | File | Origin |
|---|---|---|
| F-15E | `f15e.xml` + `F100-PW-229.xml` | JSBSim `f15` aero/FCS/engine unchanged; mass 31,700 lb empty, 9,400 lb fuel, inertias x1.22 |
| A320 | `a320.xml` + `CFM56_5.xml` | JSBSim `A320` unchanged |
| F-35B | `f35b.xml`, `f135-pw-600.xml`, `liftfan.xml` | authored (no public JSBSim model): estimated aero, FBW g/rate-command, STOVL nozzle 0-90 deg, lift fan, roll posts, yaw vectoring |
| Helicopter | `heli.xml` (generated by `tools/flight2/gen_heli.py`) | authored, **not FGRotor**: blade-element thrust + momentum inflow (dynamic lag), flap-back, hub moment, H-force, ground effect, rotor-speed/engine governor (autorotation), tail rotor, velocity-command SAS |
| DeLorean | `delorean.xml` (`gen_delorean.py`) | authored: 4 BOGEY wheels, power-limited drive force, hover mode with 4 lift thrusters |

The F-35B, helicopter and DeLorean figures are estimates, not manufacturer data.

## Verification (`tools/flight2/run_all.sh`)
Native JSBSim 1.3.3 (`pip install jsbsim`) is run with scripted stick inputs; per frame the state is fed to the C# port and forces, moments, FCS positions, engine N1/N2/thrust, fuel and CG are compared.
Native JSBSim runs Propagate first, so the forces of a frame use the *end-of-step* state, and the FCS sees the previous frame's Auxiliary values (`aero/*`, `vc`, ...); the port copies both.
F-15E, F-15 and A320: all columns within 1e-4 of scale (afterburner, gear/flap/speedbrake kinematics, fuel burn included). F-35B and helicopter (closed-loop PID/FBW): within ~0.3 % / ~1 % of scale.
`tools/flight2/fly/` flies the models headless (flat runway, same gear model): F-15E lifts off at 142 kt after 205 m, A320 at 135 kt after 827 m, F-35B vertical take-off / hover / hdot hold,
helicopter lift-off and forward flight, DeLorean 0-60 mph in about 6 s.

## Known limits
* Not play-tested in Unity: the Runtime code was compile-checked only against stubs (`tools/flight2/stubcheck`). Expect to tune gains, wheel matching and the `JsbVehicleCfg.Align` CG placement in the editor.
* The interpreter covers the elements these files use (functions, 1-3D tables, summer/gain/kinematic/filters/pid/switch/deadband/fcs_function/sensor/actuator, turbine + direct thruster, tanks, external forces and moments); f16 and other aircraft are not guaranteed.
* Inertia products (Ixz) are ignored; fuel burn changes mass but not the Rigidbody centre of mass.
* Ground friction is a velocity-limited friction model, not JSBSim's Lagrange-multiplier solver.
* A pitch-hold trim assist is added for F-15E and A320 (JSBSim has no autopilot for them).
